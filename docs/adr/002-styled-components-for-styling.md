# ADR-002: Стилизация клиента — styled-components

Дата: 2026-09-14
Статус: accepted

## Контекст

Задание запрещает inline-CSS и называет styled-components плюсом решения
(docs/assignment.md, «Будет плюсом»). Нужно выбрать библиотеку CSS-in-JS
для первого стилизованного компонента клиента (индикатор `performance`) и
дальнейшей работы. Бюджет production-сборки клиента по заданию — не больше
200 КБ gzip.

## Решение

Стилизация клиента — styled-components (`^6.5.3`).

- **Maintenance mode**: с 2025 года проект принимает только исправления,
  без новых возможностей (архивный статус разработки на GitHub). Для этого
  задания это не риск — версии зафиксированы, новые возможности не нужны;
  для долгоживущего проекта это был бы повод присмотреться к активно
  развивающейся альтернативе.
- **Цена**: сама библиотека — около 10.8 КБ gzip (замер: `esbuild --bundle
  --minify`, react помечен внешней зависимостью, т.к. уже есть в бандле) —
  близко к отраслевым оценкам «12–13 КБ». Плюс рантайм-генерация стилей:
  CSS собирается и вставляется в `<style>` при рендере компонента, а не
  на этапе сборки, что нагружает первую отрисовку сильнее, чем
  статический CSS. При бюджете 200 КБ gzip и небольшом числе
  стилизованных компонентов в задании это не критично.
- **Мотив выбора**: явный плюс в задании; синтаксис styled-components —
  компонент и его стили в одном месте, без отдельного маппинга
  классов.

## Альтернативы

- **CSS Modules** — нулевая цена в рантайме, статический CSS уже на этапе
  сборки; не упомянут в задании как плюс, а его отдельная цена (отдельные
  `.module.css`-файлы на компонент) не окупается без явного требования.
- **vanilla-extract** — статический CSS с типобезопасностью на этапе
  сборки, минимальный рантайм; более тяжёлая настройка (свой Vite-плагин,
  `.css.ts`-файлы) ради задания на 2–3 дня без явного требования к этой
  библиотеке.
- **Linaria** — статический CSS-in-JS, но с более сложной интеграцией в
  Vite и меньшим сообществом, чем у styled-components.

## Последствия

- Каждый новый стилизованный компонент клиента (дерево — задача #6,
  таблица — SPEC-002) использует styled-components, а не CSS Modules или
  inline-стили — единообразие стилизации в проекте.
- Рантайм-генерация стилей — источник затрат при рендере; если бюджет
  200 КБ gzip или время первой отрисовки станут проблемой на следующих
  этапах, пересмотр стека стилизации — повод для нового ADR
  (`supersedes ADR-002`), а не тихая замена библиотеки в отдельных
  компонентах.
